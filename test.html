WTWD 110: Foundations Instructor Guide | Lesson Plans

About This Course

This 42-hour course meets twice weekly for five weeks and equips students with core web development skills. As a result of this training, students will be able to develop basic web pages and explain HTML’s role in web development; enhance web pages with text formatting, media elements, and tables; design interactive forms and collect user input; implement and manage version control using git and GitHub; and explore advanced techniques and best practices in web development.

Web Development Foundations Learning Objectives

  • Develop basic web pages and explain HTML's role in web development
  • Enhance web pages with structured content, media, tables, and interactive forms to collect user input
  • Implement advanced CSS styling techniques
  • Apply responsive design principles, animations, & transitions
  • Implement and manage version control using Git and GitHub
  • Create wireframes and design systems in Figma

Module 2: HTML Continued 

Overview

This week, we’re focusing on the essential HTML tags and structure you need to build clear, well-organized web pages. You’ll work with elements like paragraphs, headings, lists, links, and images—learning not just how to use them, but how to make your content accessible with proper attributes like alt and href. We’ll also cover embedding media like images, video, and audio, while keeping performance in mind. By the end of the week, you’ll have hands-on experience creating pages that are functional, accessible, and ready for the next steps in web development.

 Learning Objectives

  • Identify and use essential HTML tags (like <p>, <a>, <div>) and elements (like <head> and <body>, structuring an HTML document effectively)
  • Use HTML to structure a multi-section web page with headings, paragraphs, lists, links, and images
  • Use attributes like href, src, and alt to make images more accessible
  • Embed and configure media elements like images, video, and audio, and evaluate its effect on performance

Module 3: Semantic HTML + Accessibility

Overview

This week, we’re taking a deeper look at the structure and meaning behind HTML. You’ll learn how to use semantic elements like <header>, <nav>, <article>, and <footer> to give your pages a clear, accessible layout that improves both user experience and SEO. We’ll also dive into HTML forms—how to build them properly, think through usability, and consider validation and security from the start. Along the way, we’ll talk about how HTML has evolved and why it remains a foundational part of every web application, both in how it functions and how it looks.

 Learning Objectives

  • Distinguish the roles of different HTML elements, incorporating semantic elements for accessibility and SEO.
  • Identify and use semantic tags such as <header>, <nav>, <article>, and <footer> to structure content meaningfully.
  • Use HTML form elements to design and layout forms, discussing usability, user experience, validation, and security
  • Summarize HTML's contribution to web application functionality and aesthetics, including its history and development.

Module 4: CSS Basics & Selectors

Overview

Week 4 introduces students to an essential skill in modern web development: version control using Git and GitHub. This week's curriculum is designed to provide a comprehensive understanding of version control concepts and the practical application of Git and GitHub in a collaborative web development environment. Students will learn to initialize repositories, commit changes, and manage branches using Git, gaining an understanding of how these practices contribute to efficient project management and collaboration.

 Learning Objectives

  • Identify and use CSS selectors to target HTML elements.
  • Implement styling properties to change the appearance of text, such as font, color, and size.
  • Utilize background properties to enhance the visual appeal of web elements.
  • Apply CSS box model properties including margins, borders, padding, and content.
  • Create and apply CSS classes and IDs for reusable styling.

Week 5: Advanced HTML and Best Practices

Overview

Week 5 of the course takes students deeper into the world of web development by exploring advanced techniques and best practices. This week is pivotal in understanding the sophisticated aspects of version control with Git, as well as the fundamental role of HTML in web application development. Students will analyze advanced Git features and strategies that contribute to maintaining clean and manageable Git histories, which are crucial in professional web development environments. 

 Learning Objectives

LO5: Explore Advanced Techniques and Best Practices in Web Development   

  • Analyze advanced Git features and strategies for maintaining clean and manageable Git histories.   
  • Explore the impact of Git in professional web development environments through case studies or real-world examples.   
  • Summarize HTML's contribution to web application functionality and aesthetics, including its history and development.
