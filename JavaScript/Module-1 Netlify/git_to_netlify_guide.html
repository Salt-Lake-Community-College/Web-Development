🚀 Deploy Your Portfolio: Step-by-Step Guide

This guide walks you through creating a GitHub repo, cloning it to your computer, cleaning up your portfolio files, and deploying your site to Netlify.

📦 Step 1: Create and Clone Your GitHub Repo

  1. Create a new GitHub repository (do NOT add a README or .gitignore):
    • Go to GitHub.com
    • Click New to create a repo
    • Name it something like netlify_portfolio
  2. Clone the repo to your computer using VS Code:
    3. 
# Open a new terminal in VS Code
# Make sure you are in the correct Folder for your repository
# Use the command: git clone <repo_url>
# Paste your GitHub repo URL in this command
# Run the command and clone your repo to your computer

🧹 Step 2: Add and Clean Up Your Portfolio Files

  1. View your cloned repo folder in VS Code.
  2. Drag and drop your existing portfolio files into the cloned folder.
  3. Organize your files like this:
    4. 
index.html

css/
  └── style.css

img/
  └── your-image.jpg
  4. Update file paths in your HTML:
    5. 
<link rel="stylesheet" href="css/style.css">
<img src="img/your-image.jpg" alt="Portfolio image">
  5. If showcasing other projects, create a folder inside your portfolio folder for each project you want to include.

    ⚠️ Each project folder is separate from your main portfolio's index.html 

    
      portfolio-folder/
        ├── index.html     ← main portfolio homepage
        ├── css/
        ├── img/
        └── project-one/
              ├── index.html
              ├── css/
              │    └── style.css
              └── img/
                   └── screenshot.png
  6. Test your project locally by right-clicking index.html and opening in a browser. Make sure images and styles work.

📤 Step 3: Commit and Push to GitHub

  1. Open the terminal in VS Code (or use the Git panel).
  2. Stage, commit, and push your changes:
    3. 
git add .
git commit -m "Add organized portfolio files"
git push

🌐 Step 4: Deploy to Netlify

  1. Go to Netlify.com and log in using your GitHub account.
  2. Click Add new site → Import an existing project.
  3. Select GitHub and authorize access if needed.
  4. Choose your portfolio repo from the list.
  5. Use these settings:
    • Branch to deploy: main
    • Build command: (leave blank)
    • Publish directory: ./
  6. Click Deploy site.
  7. Copy your live Netlify link and share it with your instructor!

💡 Extra Tips

  • Be consistent with folder names and file structure across all projects.
  • If your styles or images don’t show, check file paths carefully.
  • After updating your project, redeploy with: 
    
git add .
git commit -m "Update site"
git push
    Netlify will redeploy automatically!
